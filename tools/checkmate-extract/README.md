# checkmate -> ChharLAC extractor

Pulls Phoenix-authoritative mob/move data out of KiplingFFXI/checkmate
and emits two Lua files ChharLAC can consume.

## What you get

Running `extract.py` against a cloned [checkmate repo](https://github.com/KiplingFFXI/checkmate)
produces (counts current as of checkmate v1.1.0, phoenix/live 071c401048):

- **`out/moves_from_checkmate.lua`** -- 287 unique dodgeable mob TP moves
  with `kind` (aoe/cone/line/gaze), effect radius, activation range.
  Only moves with a positional shape are included; `single target` moves
  are excluded because they cannot be dodged by movement.
- **`out/nms_from_checkmate.lua`** -- 435 NM / lottery / timed / scripted
  pop entries across 164 zones, each tagged with its zone id, server
  mob IDs, spawn type, and claim-shield seconds.

## Running

Prereq: `pip install lupa --break-system-packages`

```
git clone --depth=1 https://github.com/KiplingFFXI/checkmate.git /tmp/checkmate
python extract.py --checkmate /tmp/checkmate --out ./out
```

`--limit N` processes only the first N zones for a quick smoke test.

## Why

Previous `rechhar/abilities.lua` was hand-curated from BG-wiki / FFXIclopedia
and had multiple bad entries (Metallic Body tagged `aoe`, Big Scissors
tagged `aoe` when it's single-target, Blaster `gaze` when it's `cone`).
Checkmate's data comes straight from the Phoenix server source, so the
shape of every move is ground truth.

`chhartarget/ph_database.lua` only matched by name, so a Forest Hare
anywhere in West Ronfaure printed "Jack ToD" when a totally different
hare group died. Zone-tagging solves that at the detection layer.

## Downstream merge (not auto-applied)

Two follow-ups should rebuild the live files from this data:

1. **reChhar**: replace `data/abilities.lua` with a loader that unions
   `moves_from_checkmate.lua` (ground truth) with a thin `kind` / `era`
   / `gaze` override table (for era filtering + gaze reclassification).
2. **ChharTarget**: merge `nms_from_checkmate.lua` into `ph_database.lua`
   by name, preserving existing `ph_hex_ids`/`ph_hex_ids_retail`/
   `widescan`/`location`/`notes` (user-authored metadata). Add a `zone`
   field to every entry. In `chhartarget.lua`, add
   `if entry.zone and current_zone ~= entry.zone then return end`
   right before the ToD echo in the kill handler.

Both merges are idempotent and can be re-run every time checkmate updates.
